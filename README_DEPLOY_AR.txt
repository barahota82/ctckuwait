V20 — فصل الاستخدامين
حزمة COMPANY_V20_SQLSERVER_ENV_UPLOAD.zip للاستضافة: ارفع محتويات company-site فقط. الوثائق خارج الويب.
حزمة COMPANY_V20_GITHUB_SOURCE.zip لـGitHub: مصدر بلا .env.php وبلا مفتاح تثبيت أو مرفقات أو وثائق تحتوي المفتاح.
استخدم حزمة GitHub عند الرفع من واجهة GitHub؛ الرفع عبر المتصفح لا يطبق .gitignore تلقائيًا.
.env.example.php مثال فارغ آمن للنشر. config.php وweb.config العام ملفات كود وحماية آمنة للنشر.
.gitignore يستبعد الأسرار والمرفقات والمفاتيح والنسخ الاحتياطية والسجلات. لا يدعم إزالة سر سبق نشره؛ عند نشر سر فعلي يجب تغييره وإزالته من تاريخ Git أيضًا.
عند نشر Git على خادم جديد أنشئ مفتاح التثبيت بأمر CLI: php scripts/create-install-key.php، ثم اقرأ hr/private/install.key خصوصيًا. أو استخدم مفتاح حزمة الاستضافة عبر مدير الملفات الخاص.
تحديث Git لا يحذف .env.php أو hr/private/files؛ تجنب git clean -fdx وأي مزامنة --delete تمحو الملفات غير المتعقبة.
لا تنسخ إعدادات ORANGE أو مساراته أو CNAME أو health/hash أو خدمة PWA من الموقع الآخر؛ نقلنا نمط حماية الإعدادات وما يناسب هذا النظام فقط.
