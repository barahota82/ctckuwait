# CLICK — الموقع العام وبوابة الموارد البشرية

حزمة مصدر كاملة لـ GitHub وCursor — 25 أكتوبر 2026.

ابدأ من [تعليمات التسليم لكورسور](docs/handoff/CURSOR_START_AR.md)، ثم [AGENTS.md](AGENTS.md)، واقرأ [أرشيف قرارات المالك كاملًا](docs/owner/CLICK_PENDING_BATCH_20261017_AR.txt) قبل أي تعديل. آخر توجيه صريح للمالك هو المرجع عند تعارض القرارات القديمة.

## الحالة الحالية

هذه الحزمة مبنية على المصدر الثابت بعد إصلاح أسماء ملفات الدفعات. تضم الموقع العام و`hr/` والمخطط البرمجي والاختبارات والأرشيف وأدلة المراجعة. ملفات تشغيل الموقع لم تتغير أثناء إعداد هذه الحزمة.

إصلاح الأسماء ودمج مساعدات النسخ الاحتياطي نُفّذ على الاستضافة. التحقق المحفوظ يغطي 232 ملفًا داخل HR. المراجعة الحية الشاملة لكل الشاشات والصلاحيات والأجهزة لم تكتمل؛ لا تُعتبر هذه الحزمة شهادة بخلو البرنامج من كل خطأ.

## الاستخدام

1. فك الضغط وافتح مجلد `CLICK_HR_GITHUB` في Cursor.
2. ابدأ بتعليمات `docs/handoff/CURSOR_START_AR.md`؛ لا تبدأ من ملفات README القديمة أو حزم V199 وما قبلها.
3. للمستودع: استخدم محتويات هذا المجلد، بما فيها ملفات قواعد Git وCursor. الحزمة لا تحتوي تاريخ Git أو اتصالًا بمستودع، ولم تُرفع إلى GitHub.
4. الحزمة مصدر تطوير، وليست أمرًا برفع كل مجلداتها على الاستضافة. بيانات التشغيل وإعدادات الاتصال تبقى في الخادم القائم.

## المحتويات

| المسار | المحتوى |
| --- | --- |
| `index.php`، صفحات الموقع و`assets/` | الموقع العام |
| `hr/` | بوابة الموظفين وملفات التشغيل ذات الأسماء الثابتة |
| `.env.example.php` | مثال فارغ لإعدادات بيئة مستقلة |
| `tests/` | الاختبارات الأصلية، مع اختبارات الاستكمال في `tests/current/` |
| `tests-v32/` | مصادر مقارنة لاختبارات تاريخية؛ ليست ملفات تشغيل بديلة |
| `docs/owner/` | الأرشيف الكامل دون اختصار أو حذف قرارات |
| `docs/audit/` | نتائج المراجعة وحدودها وبصمات الملفات وخريطة تغيير الأسماء |
| `docs/handoff/` | ترتيب الاستكمال وتعليمات الفحص وتسليم Cursor |
| `docs/package/` | بيان ملفات المصدر والحزمة ونتائج التحقق من تجهيزها |

## الإعداد والفحص

الكود يعتمد PHP وSQL Server في بيئة التشغيل. اختبارات السلوك المعزولة تستخدم SQLite، وبعض اختبارات الواجهة تستخدم Node.js وJSDOM. لا يوجد إطار بناء مطلوب لتشغيل ملفات JavaScript وCSS الحالية.

راجع [طريقة تشغيل الفحوص](docs/handoff/TESTING_AR.md). لا تشغّل المثبت أو الاسترجاع فوق قاعدة الإنتاج القائمة. لا تحوّل ملفات الاختبار أو بياناتها التجريبية إلى بيانات تشغيل.

الحزمة لا تتضمن `.env.php`، مفاتيح أو كلمات مرور فعلية، قاعدة البيانات، نسخها الاحتياطية، مرفقات أو صور موظفين، جلسات المتصفح أو `node_modules`. ملفات حماية `hr/private` فقط محفوظة. الأرشيف يحتوي قرارات عمل داخلية؛ المستودع الخاص هو الوجهة المناسبة لهذا المشروع.
