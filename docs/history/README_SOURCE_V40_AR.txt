CLICK V40 — مصدر كامل للمراجعة
هذا مرشح قيد التحقق التشغيلي، وليس إذنًا لمسح الاستضافة.

المصدر يضم الموقع العام وبوابة الموظفين وملفات الحجب ومثال إعدادات فارغ. لا يضم.env.php أو مفاتيح فعلية أو نسخ قاعدة البيانات أو مرفقات الموظفين أوبيانات prepared-data أو سجلات تشغيل. الاستبعاد مطبق على الملفات نفسها بالإضافة إلى.gitignore.

هذا المصدر من نفس ملفات الكود المشتركة بحزمةالاستضافة V40. بيانات التشغيل الموحدة ومفتاحنسخها وإعدادات الاستضافة موجودة فقط في الحزمةالخاصة المنفصلة.

تفاصيل المراجعة وحدودالتحقق في tests/RESULTS_AR.txt. تشغيل tests/verify-package.php يتطلب PHPCLI ولا يختبر IIS أو SQLServer. اختبارات Node المرفقةتحاكيالمتصفح؛لا تعدتجربةمتصفح أوجهاز GPS حقيقي.
لرفع GitHub فك الضغط وارفع محتويات هذه الحزمة فقط،ولا تضفحزمةالاستضافة أو أي ملفاتخاصة منخارجها. لايوجدنشرأودفعإلىمستودعتمبهذه الجلسة.
